# Plateforme collaborative en temps réel

Application realisée pour le sujet de fin de module "Web Temps Reel".

## Stack

- Backend : Node.js, Express, Socket.io, SSE
- Base de donnees : SQLite
- Frontend : HTML, TailwindCSS, JavaScript Vanilla, Chart.js via CDN
- Temps reel : WebSocket, SSE, WebRTC
